4
关键原则
贯穿整条架构链路的七条硬约束
原则 01
没有证据，不写确定结论。
原则 02
没有高置信 reference_text，不做精细发音评分。
原则 03
ASR 只代表"说了什么"，不代表"发音标准"。
原则 04
LLM Reviewer 之前先做规则校验。
原则 05
Agent 循环必须有次数上限（≤ 2 次）。
原则 06
低置信内容优先暴露给老师确认。
原则 07
老师修改结果要回流，用于持续优化系统。

单节课程成本测算
60 分钟一对一中文课 · 双音轨采集 + 仅对学生中文练习片段做发音评估
音频时长
双音轨 2 小时（老师 1h + 学生 1h），ASR 计费 7200 秒
ASR
阿里云百炼 fun-asr-flash，0.00022 元/秒
发音评估
仅评估学生中文练习片段，5-10 分钟
LLM
DeepSeek-v4-flash，报告生成 + 评审 + 修改
汇率
1 USD ≈ 7.2 RMB（Azure 换算用）
模块计费方式估算成本

DeepSeek 报告/评审5-10 万 input + 几千 output tokens¥0.05 - 0.2
存储/带宽录音临时保存< ¥0.1
≈ ¥3/ 节
主要成本来自 Azure 发音评估，其次是 ASR；LLM 报告成本极低。双音轨采集是 ASR 成本翻倍的原因——如果单音轨 + diarization，ASR 只需一半费用，但会引入说话人分离误差。
  • 中文练习片段仅 3-5 分钟：成本降至 ≈ ¥2.3/节
  • 学生整小时做发音评估：Azure 成为大头，总成本升至 ≈ ¥10/节
  • 关闭 Azure，仅 ASR + LLM：成本 ≈ ¥1.7-2/节
